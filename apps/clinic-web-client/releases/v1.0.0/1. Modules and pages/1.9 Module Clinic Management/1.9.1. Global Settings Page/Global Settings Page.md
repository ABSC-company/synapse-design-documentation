# 1.9.1. Global Settings Page

## Спецификация страницы интерфейса

* **Название страницы:** Глобальные настройки
* **Модуль:** Управление клиникой (Clinic Management Module)
* **Владеющий бэкенд-модуль:** Management Module
* **Тип страницы:** Форма настроек по разделам
* **Основные роли:** Администратор клиники (`MGMT_SETTINGS_MANAGE`)
* **Маршрут:** `/clinic-management/settings`
* **Статус документа:** Актуализировано

> Общие паттерны — см. `1.9.0. Clinic Management Overview`. Полный перечень настроек (названия, подсказки, значения, значения по умолчанию) — `Global Settings Catalog.md` в этой же папке. Бэкенд-контракт — `ManagementModule.md` §3, §5.9–§5.10, §6.

---

## Назначение страницы и сценарии использования

Страница — единое место, где администратор клиники просматривает и меняет **глобальные настройки**, действующие на всю клинику: общие данные (название, логотип, язык, часовой пояс), правила работы модулей (структура, HR, ЭМК, склад, касса, бронирование, услуги) и выбор системных справочников. Тот же набор настроек можно изменить один раз при первичной настройке системы (необязательный шаг «Настройки системы» мастера `1.1.1`); после неё настройки меняются только здесь.

Состав настроек определяет система, а не страница: при появлении новой настройки она отображается автоматически в своём разделе без изменения этой страницы. Текущий состав описан в `Global Settings Catalog.md`.

С помощью страницы пользователь может:

1. Выбрать раздел настроек из списка слева и увидеть все его настройки с названиями, подсказками и текущими значениями.
2. Изменить значения настроек элементами управления, подходящими типу настройки (текст, число, переключатель, выбор из списка, загрузка файла).
3. Сохранить изменения раздела одной кнопкой.
4. Загрузить или заменить логотип клиники.
5. Выбрать один из готовых системных вариантов справочников (стандарт пола, группы крови, категории инвалидности, классификатор заболеваний МКБ-10/МКБ-11, типы родства).
6. Понять по подсказке, на что влияет настройка, и подтвердить рискованное изменение.

---

## Доступ

* Страница доступна только пользователям с правом `MGMT_SETTINGS_MANAGE`; пункт «Глобальные настройки» остальным не показывается, прямой переход по адресу показывает сообщение об отсутствии прав.
* Страница работает только в уже инициализированной системе; до завершения первичной настройки настройки меняются в мастере `1.1.1`.

* **Левая колонка** — список разделов (Общие, Структура, HR, ЭМК, Склад, Касса, Бронирование, Услуги — в порядке, заданном системой). Раздел без настроек не показывается. Точка рядом с названием раздела означает несохранённые изменения в нём.
* **Правая область** — название раздела, кнопка «Сохранить» (закреплена в шапке области) и список настроек.

### Карточка настройки

Каждая настройка — отдельный блок:

1. **Название** (например, «Норма ежегодного отпуска (дней)»).
2. **Подсказка** — одна–две строки о назначении и последствиях настройки (серым текстом под названием; длинные подсказки раскрываются по «Подробнее»).
3. **Элемент управления** — по типу настройки (ниже).
4. **Сообщение об ошибке** — под элементом управления, красным.
5. **Пояснение о влиянии** (для настроек, меняющих правила работы или справочники) — информационная строка «Изменение действует для новых записей; существующие данные не меняются».

### Элементы управления

| Тип настройки | Элемент |
|---|---|
| Текст | Однострочное текстовое поле |
| Число | Числовое поле (только цифры) |
| Переключатель | Переключатель «Да / Нет» |
| Выбор одного из списка | Выпадающий список; для длинных списков (часовой пояс, 38 значений) — с поиском по названию |
| Файл | Загрузка изображения с превью и кнопкой «Заменить» |
| Выбор нескольких значений | Выпадающий список с чипами |
| Выбор из данных другого модуля | Выпадающий список с подгрузкой значений и индикатором загрузки |
| Повторяющаяся группа | Блок строк с «+ Добавить» и удалением строки |

Три последних типа поддерживаются системой, но в текущем составе настроек не используются (`Global Settings Catalog.md`).

## User Flows

### Flow 1. Просмотр настроек

1. Пользователь открывает «Управление клиникой → Глобальные настройки».
2. Страница показывает список разделов; по умолчанию открыт первый раздел.
3. Пользователь выбирает раздел — справа показываются его настройки с текущими значениями клиники.

### Flow 2. Изменение и сохранение раздела

1. Пользователь меняет значения; у раздела появляется индикатор несохранённых изменений, кнопка «Сохранить» становится активной.
2. Нажимает «Сохранить» — сохраняется раздел целиком (отдельное сохранение одной настройки не предусмотрено).
3. Во время сохранения кнопка показывает загрузку, поля недоступны; после успеха — сообщение «Настройки сохранены», индикатор изменений исчезает.
4. Если значение не прошло проверку, под соответствующим полем показывается ошибка, остальные введённые значения не сбрасываются, раздел остаётся несохранённым.

### Flow 3. Рискованные изменения

Для настроек, которые отключают контроль или меняют справочник, перед сохранением показывается диалог подтверждения с кратким описанием последствий:

| Изменение | Текст подтверждения |
|---|---|
| Выключен «Обязательный первичный документ по кадровым движениям» (HR) | «Кадровые движения будут применяться без сопроводительного документа» |
| Выключен «Обязательный сопроводительный документ по операциям склада» (Склад) | «Операции склада будут выполняться без сопроводительного документа» |
| Изменён «Классификатор заболеваний» (ЭМК) | «Новые диагнозы будут выбираться из выбранного классификатора; ранее сохранённые данные не изменятся» |
| Изменён «Стандарт классификации пола» (HR) | «Новые записи сотрудников будут использовать выбранный стандарт; сохранённые значения не изменятся» |

Кнопки диалога: «Отмена» (раздел остаётся несохранённым) и «Подтвердить и сохранить».

### Flow 4. Логотип клиники

1. В разделе «Общие» пользователь нажимает «Заменить» у логотипа и выбирает изображение (JPEG, PNG, SVG или WebP).
2. Файл проверяется (формат, размер); при ошибке показывается сообщение, логотип не меняется.
3. Проверенное изображение сразу загружается и показывается в превью; логотип применяется после сохранения раздела «Общие».

### Flow 5. Выбор системного справочника

Настройки-справочники (стандарт пола, группы крови, категории инвалидности, классификатор заболеваний, типы родства) выглядят как обычные выпадающие списки: пользователь выбирает один из готовых вариантов системы. Создавать, изменять или удалять собственные варианты нельзя; если вариант в списке один, список всё равно показывается (для единообразия), с подсказкой «Доступен один вариант».

### Flow 6. Уход со страницы с несохранёнными изменениями

При переключении раздела, переходе на другую страницу или закрытии вкладки с несохранёнными изменениями показывается диалог «Изменения не сохранены» с вариантами «Остаться», «Сохранить», «Отменить изменения».

## Визуал: High-Fidelity mockups

1. Двухколоночный layout: список разделов слева (закреплён при прокрутке), форма справа.
2. Кнопка «Сохранить» закреплена в шапке правой области, неактивна, пока нет изменений.
3. Индикатор несохранённых изменений — точка у названия раздела в левом списке и бейдж «Есть изменения» в шапке области.
4. Подсказки — серый текст меньшего размера; пояснение о влиянии — информационная строка с иконкой «i».
5. Переключатели с ярлыками «Да / Нет»; отключённое состояние рискованных переключателей не окрашивается в «опасный» цвет, предупреждение показывается только при сохранении.
6. Диалоги подтверждения — модальные, с кратким текстом и двумя кнопками.

Обязательные состояния для макетов: раздел с изменениями; ошибка у поля; диалог подтверждения рискованного изменения; загрузка логотипа; пустое состояние разделов.

## Состояния и edge cases

| Состояние | Ожидаемое поведение |
|---|---|
| Загрузка | Заглушки (skeleton) списка разделов и формы при открытии раздела |
| Пусто | Список разделов пуст — нейтральный текст «Настройки недоступны» (в норме не бывает) |
| Ошибка загрузки | Блок «Не удалось загрузить настройки» и кнопка «Повторить»; ошибка сохранения — сообщение, введённое не теряется |
| Нет прав | Страница недоступна без `MGMT_SETTINGS_MANAGE`: сообщение об отсутствии прав |

### Edge cases

1. Раздел с несохранёнными изменениями при переключении — диалог (Flow 6).
2. Новая настройка, появившаяся в системе, отображается без правок страницы: тип элемента выбирается автоматически; неизвестный тип показывается как нередактируемое значение с пометкой «Редактирование недоступно».
3. Список справочника с единственным вариантом — выбор остаётся доступным, смена невозможна.
4. Настройка со ссылкой на данные другого модуля, у которой не загрузился список, показывает ошибку у поля и «Повторить», остальная форма работает.
5. Параллельное редактирование раздела двумя администраторами: побеждает последнее сохранение (блокировки нет); открытый вопрос для будущей ревизии.
6. Часовой пояс и язык, изменённые в «Общих», применяются ко всей клинике; уже открытые сессии подхватывают язык по умолчанию при следующем входе (личный выбор языка сотрудника не затрагивается).

## Interaction & Animation

1. Переключение раздела — плавная смена содержимого справа, список слева не перерисовывается.
2. Сохранение — спиннер на кнопке и короткая подсветка успеха.
3. Диалог подтверждения — fade-in/out.
4. Группа настроек со строками — добавление строки со slide-down, удаление со slide-up (когда такие настройки появятся).

---

## Acceptance criteria

1. Список разделов и настройки каждого раздела отображаются автоматически по данным системы; новая настройка не требует правки страницы.
2. Все настройки из `Global Settings Catalog.md` отображаются с названием, подсказкой, текущим значением и подходящим элементом управления.
3. Раздел сохраняется целиком; ошибка значения подсвечивает конкретное поле и не сбрасывает остальные.
4. Рискованные изменения (отключение обязательных документов в HR и на складе, смена классификатора заболеваний и стандарта пола) требуют подтверждения.
5. Логотип клиники загружается и показывается в превью до сохранения раздела «Общие».
6. Выбор справочников ограничен готовыми вариантами системы; собственные варианты создать нельзя.
7. Несохранённые изменения не теряются без подтверждения.
8. Страница доступна только с правом `MGMT_SETTINGS_MANAGE`.
