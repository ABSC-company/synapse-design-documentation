# 1.9.1. Каталог глобальных настроек

## Назначение документа

Перечень **всех глобальных настроек клиники**, существующих в системе, в том виде, в каком их видит пользователь: раздел, название, подсказка, элемент управления, допустимые значения и значение по умолчанию. Используется одинаково на:

* странице `1.9.1. Global Settings Page` (Управление клиникой → Глобальные настройки);
* необязательном шаге «Настройки системы» мастера первичной настройки (`1.1.1. System Initialization Page`, Шаг 4).

Состав настроек задаётся приложением и меняется вместе с его релизом (формы описаны на стороне приложения; сервер хранит только значения и проверяет их допустимость). Этот каталог фиксирует состав настроек на момент ревизии и должен обновляться при добавлении или изменении настроек.

Названия и подсказки на экране показываются на языке интерфейса (здесь приведены русские тексты).

| Категории инвалидности | Набор категорий инвалидности. Выбирается один из системных наборов. | Выпадающий список («Выберите набор категорий инвалидности») | Группы инвалидности (РУз) | Группы инвалидности (РУз) |
| Классификатор заболеваний | Классификатор хронических заболеваний. Выбирается один из системных классификаторов. | Выпадающий список («Выберите классификатор заболеваний») | ICD-10 (МКБ-10); ICD-11 (МКБ-11) | ICD-10 |
| Типы родственных связей | Набор типов родственных связей пациента. Выбирается один из системных наборов. | Выпадающий список («Выберите набор типов родства») | Базовый набор | Базовый набор |

Примечания:
* Четыре настройки-справочника (группы крови, категории инвалидности, классификатор заболеваний, типы родства) — **выбор одного из готовых системных вариантов**; создавать свои варианты нельзя. Сейчас у трёх из них один вариант, у классификатора заболеваний — два.
* **Классификатор заболеваний** определяет, какой каталог кодов (МКБ-10 или МКБ-11) сотрудники используют при выборе диагнозов в ЭМК и при подстановке кодов в документы. Смена действует на новые выборы; ранее сохранённые диагнозы и созданные документы не меняются. При изменении показывается пояснение «Новые диагнозы будут выбираться из выбранного классификатора».
* «Возраст совершеннолетия» и «Система измерения» применяются к новым и редактируемым записям пациентов.

## Общие правила для настроек

* **Типы элементов** в текущем составе: текстовое поле, числовое поле, переключатель, выпадающий список (один выбор), загрузка файла. Других типов (множественный выбор, список сущностей других модулей, повторяющиеся группы) в составе настроек нет.
* Каждая настройка отображает название, подсказку под названием и текущее значение; изменённое, но не сохранённое значение отмечается индикатором.
* Значения по умолчанию — те, что поставляются с системой до первого изменения; после сохранения показывается текущее значение клиники.
* Все настройки применяются ко всей клинике.
