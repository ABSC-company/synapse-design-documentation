# 1.6.8 Time Tracking (Табель учёта времени)

## Спецификация страницы интерфейса

* **Название страницы:** Табель учёта рабочего времени
* **Модуль:** HR (Human Resources)
* **Тип страницы:** Табель-сетка (сотрудники × дни) + итоги
* **Основные роли:** Администратор / HR-менеджер, Руководитель отдела
* **Маршрут:** `/hr/time-tracking`
* **Платформа:** веб-приложение медицинской системы
* **Статус документа:** Актуализировано

> Общие паттерны — см. `1.6.0. Overview`. Учёт времени конкретного сотрудника также доступен в его эл. деле (1.6.4, календарь). Техническая реализация — во frontend-документе `1.6.8. Time Tracking` (Frontend).

---

## Назначение страницы и сценарии использования

Сводный табель по сотрудникам за выбранный период: отметки прихода и ухода, отработанное время, опоздания, пропуски. Сотрудники отмечают приход и уход сами кнопкой в шапке; HR корректирует отметки вручную (забытый приход, незакрытая смена).

С помощью страницы пользователь может:

1. Просматривать табель за месяц по сотрудникам и дням.
2. Искать и фильтровать по ФИО, отделу, должности; листать страницы сотрудников.
3. Видеть итоги: отработанное время (часы и минуты), опоздания, пропуски.
4. Корректировать отметки (добавить, изменить, удалить) при наличии прав.
5. Выгружать табель в XLSX и PDF или печатать.
6. Управлять календарём нерабочих дней клиники в модальном окне.

---

## User Flows / Task Flows

### Flow 1. Просмотр табеля
1. Пользователь открывает «Табель», выбирает месяц.
2. Система показывает страницу сотрудников и сетку дней с состояниями и итогами.
3. Ищет сотрудника или фильтрует по отделу и должности, листает страницы.

### Flow 2. Корректировка отметки
1. Клик по ячейке дня сотрудника открывает поповер с отметками дня.
2. Пользователь добавляет, меняет или удаляет отметку (приход, уход), сохраняет.
3. Закрытая теперь смена пересчитывает часы; ячейка получает значок «Корректировка».

### Flow 3. Выгрузка
1. «Экспорт» → формат (XLSX, PDF, печать) → файл по текущему периоду и фильтрам.

### Flow 4. Нерабочий день
1. «Нерабочие дни» открывает модальное окно со списком дней года.
2. «Добавить день» → дата, название, вид (праздничный / нерабочий).
3. Перед сохранением показывается предупреждение, сколько записей пациентов на эту дату будет отменено (предварительных и оплаченных), и требуется подтверждение.
4. После сохранения день выделяется в табеле и в календаре дашборда.

## Структура: Wireframes

### Общий layout
```
┌─────────────────────────────────────────────────────────────────────────────────┐
│  Табель учёта времени   ◀ Июнь 2026 ▶   🔍 Поиск  [Фильтр ▾] [Нерабочие дни] [Экспорт]│
├──────────────┬──┬──┬──┬──┬──┬──┬──┬──┬───┬───────────┬───────┬──────────────────┤
│  Сотрудник   │1 │2 │3 │4 │5 │6 │7 │…│30 │ Σ время   │Опозд. │ Пропуски          │
├──────────────┼──┼──┼──┼──┼──┼──┼──┼──┼───┼───────────┼───────┼──────────────────┤
│ Иванов И.    │✓ │✓ │— │✓ │L*│  │  │…│✓  │ 168 ч 20 м│   2   │    1              │
│ Петрова А.   │✓ │О │О │О │О │  │  │…│✓  │ 152 ч 00 м│   0   │    0              │
└──────────────┴──┴──┴──┴──┴──┴──┴──┴──┴───┴───────────┴───────┴──────────────────┘
   « 1 2 3 … »   (страницы сотрудников)
   Легенда: ✓ отработан · L опоздание · — пропуск · О отпуск · Б больничный · К командировка
            ▒ нерабочий день · ⚠ открытая смена · * корректировка
```

### Управление
* Переключатель периода (месяц, не более 62 дней).
* Поиск по ФИО и «Фильтр» (Drawer): отдел, должность.
* «Нерабочие дни» — модальное окно календаря клиники.
* «Экспорт»: XLSX / PDF / печать (файл формирует сервер).
* Пагинация по сотрудникам внизу.

### Ячейка дня
* Состояния: отработан, опоздание, пропуск, отпуск / командировка / больничный и прочие отсутствия (из журнала отсутствий 1.6.9), выходной по графику, нерабочий день клиники (штриховка), до приёма и после увольнения (пусто), будущий день.
* Открытая смена (приход без ухода) подсвечена предупреждающим значком; в часы она не входит.
* Значок `*` — отметка внесена или изменена HR.
* Hover — подсказка: приход, уход, отработанное время в формате «8 ч 51 мин».

**Поповер дня:**
```
┌────────────────────────────────────┐
│  Иванов И. · 05.06.2026         [✕]│
├────────────────────────────────────┤
│  ⬇ Приход   09:12   сам    [✏][✕]  │
│  ⬆ Уход     18:03   HR *   [✏][✕]  │
│  Отработано: 8 ч 51 мин · Опоздание │
│              [+ Добавить отметку]   │
├────────────────────────────────────┤
│              [Закрыть]   [Сохранить]│
└────────────────────────────────────┘
```
У каждой отметки видно, кто её внёс (сам сотрудник или HR). «+ Добавить отметку» и `[✏]` — тип (приход, уход) и дата-время.

### Итоговые колонки
Σ времени за период в формате «168 ч 20 мин», число опозданий, число пропусков. Внизу таблицы — итоги по всей выборке (всем страницам), отдельно число открытых смен.

### Модальное окно «Нерабочие дни»
```
┌──────────────────────────────────────────────┐
│  Нерабочие дни клиники          ◀ 2026 ▶  [✕]│
├──────────────────────────────────────────────┤
│  01.01  Новый год                 праздничный │ [✏][✕]
│  08.03  Международный женский день праздничный│ [✏][✕]
│  …                                            │
│  [+ Добавить день]                            │
└──────────────────────────────────────────────┘
```
Форма добавления: дата, название, вид (праздничный / нерабочий) и флажок «Повторять каждый год». Ежегодные дни помечены значком повтора. Перед сохранением: «На эту дату (для ежегодного дня — на все будущие вхождения) N предварительных и M оплаченных записей будут отменены, пациентам уйдёт уведомление, оплаченные записи уйдут в возврат». Без права управления окно только для чтения.

## Состояния и edge cases

* **Empty:** «Нет данных за выбранный период» / «Ничего не найдено» по поиску.
* **Loading:** скелетон сетки; спиннер при экспорте.
* **Error:** блок ошибки + «Повторить»; toast при сбое сохранения отметки.
* **Offline:** табель из кэша; правка заблокирована, toast.
* **Permissions:** без права на просмотр — раздел недоступен; без права на правку — отметки только для чтения; без права управления календарём окно «Нерабочие дни» только для чтения.
* **Edge cases:** приход без ухода (открытая смена) — подсветка, в часы не входит, закрывается ручным уходом; уход без прихода — значок; ночные смены (уход на следующий день) относятся ко дню прихода; день отсутствия, нерабочий день и выходной не считаются пропуском; до приёма и после увольнения день пуст; большое число сотрудников — серверная пагинация.

## Interaction & Animation

* Смена месяца — слайд сетки; прокрутка дней с залипающей колонкой сотрудника.
* Hover ячейки — подсветка строки и столбца и тултип с деталями.
* Поповер дня — fade+scale у ячейки; сохранение — спиннер на кнопке.
* Экспорт — индикатор подготовки файла. Toast — выезд, авто-скрытие 3–5 с.

## Зависимости и ограничения

* Отделы и должности — Structure Module; журнал отсутствий (1.6.9) — типы дней; календарь нерабочих дней — HR Module.
* Связь с 1.6.4 (календарь учёта в деле) и 1.3 Booking (нерабочие дни закрывают запись).
* Норма времени и опоздания берутся из графика сотрудника (1.6.4) и допуска на опоздание в настройках клиники.
* Отметки вносят сотрудники сами (кнопка в шапке) или HR; автоматических источников в релизе 1 нет.

## Acceptance criteria

* Табель показывает сетку «сотрудники × дни» за период с пагинацией, поиском и фильтрами по отделу и должности.
* Ячейки отражают состояние дня с легендой; открытая смена и корректировки помечены.
* Итоги показывают время в часах и минутах, опоздания и пропуски; итоги по выборке считаются по всем страницам.
* Правка и добавление отметок доступны только при праве; у отметки виден автор.
* Экспорт в XLSX и PDF формирует сервер по текущему периоду и фильтрам; печать доступна.
* Окно «Нерабочие дни» предупреждает, сколько записей будет отменено, и требует подтверждения.
* Состояния empty / loading / error / offline / permissions обрабатываются корректно.
