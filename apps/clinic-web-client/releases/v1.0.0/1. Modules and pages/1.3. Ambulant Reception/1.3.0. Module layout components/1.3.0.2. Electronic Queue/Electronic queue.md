Компонент «Электронная очередь» — фиксированный правый блок на страницах модуля Регистратуры.

Он может занимать всю доступную высоту контента или сочетаться с соседним компонентом в одной обёртке, например с календарём.

Основная структура компонента:

- Header
  - Название очереди, например: «Регистратура. Окно 3».
  - Список окон точки очереди, из которого пользователь выбирает текущее рабочее окно — выбор занимает окно за сотрудником: пока окно не выбрано явно, сотрудник не участвует в обслуживании общей очереди. Если у точки только одно окно (типичный случай приёма врача) — занятие может происходить автоматически при открытии рабочей страницы, без отдельного выбора в списке.
  - Две основные кнопки‑триггеры:
    - приостановка очереди — временная пауза именно занятого окна, не всей точки: остальные окна той же точки продолжают вызывать из общей очереди;
    - вызов следующего посетителя — берёт следующий номер из **общей** очереди точки (не «своей» очереди окна — очередь одна на все окна точки, номера, уже взятые другим окном, в списке ожидания не показываются).

- Body
  - Список карточек текущей электронной очереди.
  - Каждая карточка содержит:
    - порядковый номер;
    - время становления в очередь;
    - время ожидания.
  - Отдельная свёрнутая по умолчанию секция «Пропущенные» — талоны с отметкой «Неявка», вызванные на это окно/точку сегодня, но не подошедшие; не участвуют в основном списке ожидания, поэтому не смешиваются с обычными карточками. Секция показывает только талоны, привязанные к визиту — только у них есть кнопка «Вернуть в очередь»: талон без визита (выданный на киоске, никогда не превратившийся в приём) после неявки — действительно конец истории, для него секция показывает лишь сам факт неявки, без действия. Каждая карточка секции — номер талона, ФИО пациента.
  - «Вернуть в очередь» — открывает Booking Scheduler (`1.3.2. Booking Page`) на сегодняшней дате, отфильтрованный на врача этого приёма, со свободными и занятыми ячейками графика; пользователь кликает свободную ячейку — система переносит время соответствующей консультации на выбранный слот и возвращает **этот же** талон в ожидание (новый не выпускается — талон, привязанный к визиту, живёт до его завершения) — карточка сама перемещается из «Пропущенных» обратно в основной список ожидания этого же виджета, встаёт в общий порядок очереди наравне с остальными — не занимает чьё-то место.

Данные карточек приходят одним ответом списка талонов точки: номер, время выдачи, время ожидания в минутах, ФИО пациента, врач и консультации визита (для возврата в очередь), поэтому дополнительных запросов за пациентом и визитом виджет не делает. Состав окон и «моё окно» приходят вместе с точкой; список обновляется по событиям живых обновлений, без опроса.

Требования к оформлению:

- Блок должен быть визуально отделён от основного контента страницы.
- Заголовок очереди должен быть чётким и легко читаемым.
- Кнопки управления очередью должны быть доступны и заметны.
- Список карточек должен быть компактным, но информативным, с акцентом на номер и текущее ожидание.

Варианты использования:

- Полноэкранный вид: когда «Электронная очередь» занимает всю высоту доступной контентной области.
- Комбинированный вид: когда компонент расположен рядом с дополнительным модулем, например календарём, в единой обёртке.

Этот виджет — лишь часть более широкой системы электронной очереди, включающей киоск выдачи талонов ([Kiosk Ticket Issue Page.md](../../../1.15%20Module%20Electronic%20Queue/Kiosk%20Ticket%20Issue%20Page.md)) и публичные мониторы табло в масштабе точки очереди целиком либо отдельного окна — в т.ч. монитор у кабинета врача, технически тот же тип табло ([Queue Display Monitors.md](../../../1.15%20Module%20Electronic%20Queue/Queue%20Display%20Monitors.md)). Оба документа — в отдельном модуле «Электронная очередь» (`1.15`).

## Ограничение по сертификату

Если у сотрудника просрочен сертификат по специализации, а в настройках клиники включена блокировка работы с пациентами, виджет сам показывает предупреждение и отключает действия с пациентами. Пока блокировка действует:

- в верхней части страницы баннер: «Работа с пациентами недоступна: истёк сертификат по специализации «…» (до …), аттестация не пройдена. Обратитесь в HR»;
- действия «Занять окно», «Вызвать следующего» отключены с той же подсказкой;
- просмотр данных остаётся доступным.

Бессрочные сертификаты и сотрудники без специализаций с категорией не ограничиваются. При выключенной настройке баннера и блокировок нет.
