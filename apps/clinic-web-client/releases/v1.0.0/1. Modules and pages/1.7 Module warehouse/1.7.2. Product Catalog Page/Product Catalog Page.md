# 1.7.2 Product Catalog Page (Каталог товаров)

## Спецификация страницы интерфейса

* **Название страницы:** Каталог товаров
* **Модуль:** Warehouse (Склад)
* **Тип страницы:** Реестр + карточка
* **Маршрут:** `/warehouse/products`
* **Статус документа:** Актуализировано

> Общие паттерны — см. `1.7.0. Warehouse Overview`. Техническая реализация — `1.7.2. Product Catalog`.

---

## Назначение страницы и сценарии использования

Справочник расходных материалов клиники: наименование, единица измерения, упаковка, условия хранения (температура/влажность), категории и текущий остаток (общий или по конкретному складу).

С помощью страницы пользователь может:

1. Просматривать каталог, искать по названию, фильтровать по категории и складу (остаток именно там).
2. Добавлять/редактировать карточку товара с условиями хранения и категориями.
3. Управлять справочником категорий.
4. Удалять карточку товара, если нет привязок к поставкам/остаткам.

---

## User Flows / Task Flows

### Flow 1. Добавление товара
1. «+ Добавить товар» → форма: название, ед. измерения, упаковка, диапазоны температуры/влажности (опционально), категории (мульти-select).
2. Сохранение → товар появляется в каталоге с нулевым остатком.

### Flow 2. Просмотр остатков по складу
1. Пользователь выбирает конкретный склад в фильтре «Остатки по складу».
2. Колонка «Остаток» пересчитывается под выбранный склад (запрос с `storage_id`), не общий по клинике.

### Flow 3. Управление категориями
1. «Категории ▾» → «Управление категориями» открывает мини-реестр (CRUD) поверх каталога.
2. Удаление категории снимает её со всех товаров без предупреждения по каждому — общее предупреждение «Категория будет снята с N товаров».

## Состояния и edge cases

### Empty
Нет товаров — «Каталог пуст» + «+ Добавить товар». Нет результатов фильтра — «Ничего не найдено» + «Сбросить фильтры».

### Loading / Error
Скелетон таблицы; блок ошибки + «Повторить».

### Permissions
Нет права — раздел скрыт. Нет прав на управление — кнопки создания/редактирования/удаления скрыты.

### Edge cases
* Удаление товара с привязками (поставки/остатки) заблокировано с пояснением.
* Диапазоны температуры/влажности необязательны — не все товары чувствительны к хранению.

## Interaction & Animation

Стандартные для реестра: fade при загрузке, slide-in для форм/дровера категорий.

## Зависимости и ограничения

Категории — собственный справочник модуля (`product_categories`), не переиспользуется другими модулями.

## Роли / права

| Действие | Право |
|---|---|
| Просмотр | `WAREHOUSE_PRODUCT_GET` |
| Создание | `WAREHOUSE_PRODUCT_CREATE` |
| Редактирование | `WAREHOUSE_PRODUCT_UPDATE` |
| Удаление | `WAREHOUSE_PRODUCT_DELETE` |
| Категории | `WAREHOUSE_PRODUCT_CATEGORY_MANAGE` |

---

## Acceptance criteria

* Каталог показывает название/ед. изм./категории/остаток/статус, поддерживает поиск, фильтр по категории и складу, пагинацию.
* Форма товара включает условия хранения и мульти-select категорий.
* Управление категориями доступно из каталога без перехода на отдельную страницу.
* Удаление заблокировано при активных привязках.
* Состояния empty/loading/error/permissions обработаны.
