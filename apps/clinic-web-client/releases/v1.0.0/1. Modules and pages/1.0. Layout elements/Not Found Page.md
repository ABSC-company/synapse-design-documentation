# 1.0.3. Страница 404 «Страница не найдена»

## Спецификация страницы интерфейса

* **Название страницы:** Страница не найдена (404) и её варианты — «Запись не найдена» и «Нет доступа»
* **Модуль:** Общие компоненты лейаута (Layout elements)
* **Позиция:** Служебная страница, показывается вместо любой страницы системы, когда её невозможно открыть
* **Тип страницы:** Информационная (без форм и данных)
* **Основные роли:** Любой пользователь, в том числе не вошедший в систему
* **Статус документа:** Draft
* **Платформа:** веб-приложение медицинской системы (десктоп и планшет)

---

## Назначение страницы и сценарии использования

Страница объясняет пользователю, что открыть нужное не удалось, и возвращает его в работу одним нажатием. Она не должна пугать и не должна выглядеть как сбой системы.

Сценарии:

1. Пользователь ввёл или открыл по закладке адрес, которого не существует — «Страница не найдена».
2. Пользователь открыл ссылку на пациента, визит, документ или счёт, которых уже нет (удалены, архивированы, ссылка устарела) — «Запись не найдена».
3. Пользователь открыл ссылку на раздел, на который у него нет прав — «Нет доступа».
4. Пользователь не вошёл в систему и открыл несуществующий адрес — страница показывается без меню, с кнопкой «Войти».

## User Flows / Task Flows для страницы

### Flow 1. Несуществующий адрес

1. Пользователь открывает адрес, которого нет в системе.
2. Страница показывается внутри обычного каркаса (шапка и меню слева остаются): крупное «404», заголовок «Страница не найдена», пояснение «Возможно, адрес введён с ошибкой или страница была перемещена».
3. Пользователь нажимает «На главную» — открывается его рабочая страница (по роли), либо «Назад» — возврат на предыдущую страницу.

### Flow 2. Запись не найдена

1. Пользователь открывает страницу конкретной записи (например, карточку пациента), а такой записи нет.
2. На месте содержимого показывается «Запись не найдена» с пояснением «Возможно, она удалена или у вас нет к ней доступа».
3. Кнопки те же: «На главную» и «Назад».

### Flow 3. Нет доступа

1. Пользователь открывает раздел, к которому у него нет доступа.
2. Показывается «403», заголовок «Нет доступа», пояснение «У вас нет прав для просмотра этого раздела. Обратитесь к администратору».
3. Кнопки «На главную» и «Назад».

### Flow 4. Пользователь не вошёл в систему

1. Открыт несуществующий адрес без входа.
2. Страница показывается по центру пустого экрана, без шапки и меню; вместо «На главную» — кнопка «Войти».

## Структура: Wireframes

```
┌───────────────────────────────────────────────────────────────────────┐
│ Шапка (как на всех страницах)                                         │
├──────────┬────────────────────────────────────────────────────────────┤
│ Меню     │                                                            │
│ слева    │                    [ иллюстрация ]                         │
│          │                          404                               │
│          │                 Страница не найдена                        │
│          │     Возможно, адрес введён с ошибкой или страница          │
│          │                  была перемещена                           │
│          │                                                            │
│          │            [ На главную ]   [ Назад ]                      │
└──────────┴────────────────────────────────────────────────────────────┘
```

Состав блока (по центру контентной области, по вертикали — чуть выше середины):

1. Иллюстрация — спокойная, нейтральная (без «аварийных» красных тонов).
2. Крупный код — «404» (для «Нет доступа» — «403»).
3. Заголовок — одна строка.
4. Пояснение — одно–два предложения, не длиннее двух строк.
5. Кнопки: основная «На главную» (акцентная), вторичная «Назад» (контурная). Если предыдущей страницы нет (ссылку открыли напрямую), «Назад» не показывается.

### Тексты

| Вариант | Код | Заголовок | Пояснение |
|---|---|---|---|
| Страница не найдена | 404 | Страница не найдена | Возможно, адрес введён с ошибкой или страница была перемещена |
| Запись не найдена | 404 | Запись не найдена | Возможно, она удалена или у вас нет к ней доступа |
| Нет доступа | 403 | Нет доступа | У вас нет прав для просмотра этого раздела. Обратитесь к администратору |

Тексты доступны на русском, английском и двух вариантах узбекского; узбекские тексты подлежат проверке носителем языка.

## Визуал: High-Fidelity mockups

Визуальные правила:

1. Страница оформляется как обычная страница системы: тот же фон, шрифты и кнопки, что в остальных разделах.
2. Код «404»/«403» — самый крупный элемент, но в приглушённом цвете (не основной акцент).
3. Иллюстрация одинакова для всех вариантов, различаются только код и тексты.
4. Тёмная и светлая темы поддерживаются.

Обязательные макеты:

1. Вариант «Страница не найдена» внутри каркаса (развёрнутое меню).
2. Тот же вариант со свёрнутым меню.
3. Вариант «Запись не найдена».
4. Вариант «Нет доступа».
5. Вариант без входа в систему (без шапки и меню).
6. Планшетная версия.

## Состояния и edge cases

| Состояние | Ожидаемое поведение |
|---|---|
| loading | Не требуется: страница показывается мгновенно |
| offline | Страница показывается как обычно, баннер отсутствия сети — из общего каркаса |
| permissions | Для вошедшего — «На главную»; для не вошедшего — «Войти» |

### Edge cases

1. Ссылка открыта в новой вкладке напрямую — кнопки «Назад» нет.
2. Адрес в строке браузера не меняется, чтобы пользователь мог скопировать его и передать администратору.
3. У пользователя нет ни одного доступного раздела — «На главную» ведёт на экран «Нет доступных разделов».
4. Сеанс истёк, пока открыта страница 404, — переход на страницу входа, после входа открывается рабочая страница пользователя, а не недействительный адрес.
5. Очень длинный адрес в пояснении не выводится; пояснения фиксированные.

## Interaction & Animation

1. Появление страницы — мягкое проявление (fade) без прыжков.
2. Кнопки получают фокус с клавиатуры в порядке: «На главную», «Назад»; Enter активирует.
3. Иллюстрация неподвижна (без постоянной анимации), чтобы не отвлекать.

## Acceptance criteria

1. Любой несуществующий адрес открывает страницу «Страница не найдена» внутри каркаса для вошедшего и без каркаса — для не вошедшего.
2. Ссылка на отсутствующую запись показывает «Запись не найдена», на закрытый раздел — «Нет доступа».
3. «На главную» ведёт на рабочую страницу пользователя; «Назад» скрыта, если истории нет.
4. Тексты переключаются вместе с языком интерфейса.
5. Страница выглядит одинаково аккуратно в светлой и тёмной темах и на планшете.
