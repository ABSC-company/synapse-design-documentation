## Состав меню

Sidebar — главное меню системы. Содержимое формируется для каждого сотрудника отдельно: он видит только те разделы и пункты, к которым ему предоставлен доступ. Разделы без доступных пунктов не показываются совсем.

### Разделы и пункты (порядок сверху вниз)

| Раздел | Пункты |
|---|---|
| Регистратура | Визиты и запись; Пациенты (ЭМК) |
| Врач | Визиты; Склад отделения |
| Исследования | Очередь исследований; Склад отделения |
| Сестринский персонал | Визиты в клинику; Склад отделения |
| Касса | Рабочий стол; Смены; Отчёты; Счета |
| Документы | Документы (с бейджем числа документов, ожидающих действия) |
| Склад | Поставщики; Каталог товаров; Заказы на поставку; Остатки и партии; Склады; Запросы на пополнение; ТМЦ; Ревизии; Складское делопроизводство |
| Кадры | Главный дашборд; Структура; Сотрудники; Штатное расписание; Инструктажи; Аттестации; Табель учёта времени; График отсутствий; Кадровое делопроизводство |
| Управление клиникой | Глобальные настройки; Роли и права; Доступ сотрудников; Кассы; Склады; Каталог услуг; Ресепшен и очереди; История аудита; Аналитика и отчёты |

Отдельного раздела «Главная» нет: после входа сотрудник попадает на свою рабочую страницу (врач — в «Визиты» врача, лаборатория — в очередь исследований, медсестра — в визиты, регистратура — в «Визиты и запись», остальные — в «Аналитику» либо в первый доступный пункт). Если ни одного раздела нет — экран «Нет доступных разделов, обратитесь к администратору».

### Примеры отображения (для макетов)

| Сотрудник | Что видит в меню |
|---|---|
| Врач | Врач (Визиты, Склад отделения); Документы |
| Регистратор | Регистратура (Визиты и запись, Пациенты); Документы; Касса, если регистратуре разрешено принимать оплату |
| Лаборант | Исследования (Очередь исследований, Склад отделения); Документы |
| Кассир | Касса (Рабочий стол, Смены, Отчёты, Счета); Документы |
| Кладовщик | Склад (все страницы склада); Документы |
| Кадровик | Кадры (все страницы кадров); Документы |
| Администратор клиники | Все разделы, включая «Управление клиникой» |

### Поведение

1. Состав Sidebar определяется при входе пользователя.
2. Изменение прав обновляет структуру меню без перезагрузки.
3. Пользователь не видит разделы, на которые у него нет доступа.
4. При прямом переходе по ссылке к недоступному разделу система показывает страницу «Нет доступа» (см. `Not Found Page.md`).
5. Структура меню одинакова в развёрнутом и свёрнутом режимах: в свёрнутом режиме показаны иконки разделов, пункты раскрываются подменю при наведении или нажатии. Выбранный режим запоминается.
6. Активный пункт подсвечен, его раздел раскрыт.
7. Пункт «Документы» показывает бейдж с числом документов, ожидающих действий пользователя (подпись или ознакомление); число то же, что на вкладке «Входящие» страницы «Документы». Бейдж скрыт при нуле, при числе больше 99 показывается «99+». Других бейджей в меню нет.

## Нижняя часть Sidebar

В нижней части Sidebar, под списком разделов модулей, закреплены два элемента (всегда видны, прокрутка списка разделов их не затрагивает):

1. **Поддержка** — переход на внешний сервис поддержки
2. **Руководство по системе** — переход на внешний сервис с руководством пользователя

### Внешний вид

- у каждого элемента — иконка и подпись; элементы **не сворачиваются**: подпись видна всегда, в любом режиме Sidebar (в свёрнутом режиме иконка располагается над подписью, текст переносится на две строки), это полноценные кнопки, а не пункты меню
- визуально отделены от списка разделов тонкой линией и не подсвечиваются как «активный раздел» (это не страницы приложения)
- у элементов есть признак внешней ссылки (небольшая иконка «стрелка из квадрата» справа от подписи в развёрнутом режиме)

### Поведение

- Клик по элементу открывает внешний сервис **в новой вкладке** браузера; текущая страница приложения не закрывается и не теряет несохранённые данные
- Элементы доступны **всем ролям** и не зависят от прав доступа
- Ссылки на внешние сервисы пока не заданы: пока ссылка пустая, элемент отображается неактивным (приглушённый), при наведении подсказка «Ссылка пока не настроена»
- Других элементов в нижней части Sidebar нет
