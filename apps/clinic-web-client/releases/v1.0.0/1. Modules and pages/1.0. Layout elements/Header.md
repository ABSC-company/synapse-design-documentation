# Global Header

## Описание компонента

**Global Header** — глобальная панель навигации системы, расположенная в верхней части интерфейса и отображаемая на всех страницах приложения.

Компонент предназначен для:

- отображения текущего местоположения пользователя в системе;
- быстрого поиска ЭМК пациентов;
- доступа к уведомлениям;
- перехода в профиль пользователя;
- управления боковым меню приложения.

---

## Структура компонента

Компонент состоит из следующих элементов:

---

## Кнопка управления Sidebar

Расположена в левой части Header рядом с логотипом системы.

### Поведение

1. При нажатии открывает Sidebar, если он скрыт.
2. При повторном нажатии сворачивает Sidebar.
3. Состояние Sidebar сохраняется до изменения пользователем.

---

## Breadcrumb Navigation

Расположена после кнопки Sidebar.

Предназначена для отображения текущего пути пользователя внутри системы.

### Формат отображения

Главная → Раздел → Подраздел → Текущая страница

### Поведение

1. Все промежуточные элементы являются ссылками.
2. Текущая страница отображается как активный элемент.
3. При переходе между страницами Breadcrumb обновляется автоматически.

### Пример

Главная → Регистратура → Визиты

---

## Глобальный поиск ЭМК

Расположен в правой части Header.

Предназначен для быстрого поиска пациентов и перехода в их ЭМК.

### Task Flow

#### Этап 1. Ввод поискового запроса

Пользователь вводит поисковый запрос.

Поддерживаемые типы поиска:

- Ф.И.О пациента
- ID пациента
- PINFL
- номер телефона
- номер документа
- FaceID
- MRZ

---

#### Этап 2. Выполнение поиска

Поиск выполняется автоматически с использованием дебаунсинга.

---

#### Этап 3. Отображение результатов

Отображается выпадающий список найденных пациентов.

Для каждого результата:

- Ф.И.О пациента
- идентификатор пациента
- дата рождения
- фотография пациента (если есть)

---

#### Этап 4. Переход в ЭМК

При выборе пациента открывается его электронная медицинская карта.

---

## Центр уведомлений

Расположен справа от строки поиска.

Предназначен для отображения уведомлений пользователя (сотрудника), связанных с бизнес-процессами клиники и работой самой системы: задачи, документы, визиты, исследования, электронная очередь, файлы, действия других пользователей. Пароли, коды подтверждения и уведомления пациентов в Центре уведомлений не показываются — они приходят вне приложения.

---

## Индикатор непрочитанных уведомлений

- Если есть непрочитанные уведомления, в иконке отображается **красный кружок** (без числа)
- Индикатор исчезает, когда все уведомления прочитаны
- Индикатор появляется сразу, как только приходит новое уведомление — без перезагрузки страницы

---

## Дропдаун уведомлений

Открывается при клике на иконку уведомлений.

### Структура

#### Список уведомлений

Отображает последние уведомления пользователя.

Каждое уведомление содержит:

- тип уведомления
- краткое описание
- дата и время
- статус (прочитано / не прочитано)
- ссылка на связанный объект (если есть)

Непрочитанные уведомления визуально выделяются.

---

### Поведение

- Список подгружается порциями по мере прокрутки вниз
- Непрочитанное уведомление становится прочитанным, когда пользователь пролистал список и оно попало в видимую область (выделение непрочитанного плавно гаснет); если до него не дошли прокруткой — оно остаётся непрочитанным
- При клике на уведомление выполняется переход к связанному объекту, уведомление сразу помечается прочитанным
- Изменения статуса происходят без перезагрузки

---

### Кнопка «Отметить все как прочитанные»

Расположена в шапке дропдауна (справа от заголовка «Уведомления»), текстовая кнопка.

#### Поведение

- Нажатие помечает прочитанными **все** непрочитанные уведомления пользователя сразу, не только загруженные в список
- Выделение непрочитанных гаснет у всех строк, красный кружок на колокольчике скрывается
- Кнопка неактивна (disabled), если непрочитанных уведомлений нет, и во время выполнения действия
- Подтверждение не запрашивается; при ошибке показывается сообщение «Не удалось отметить уведомления», статусы возвращаются как были

---

### Нижняя кнопка drop down

Содержит кнопку:

- **Посмотреть все уведомления**

#### Поведение

- Открывает driver-компонент (drawer)
- Закрывает dropdown

---

## Driver-компонент уведомлений

Выезжающая панель со всеми уведомлениями и фильтрацией.

---

### Заголовок

- Уведомления
- Справа — кнопка **«Отметить все как прочитанные»**: помечает прочитанными все непрочитанные уведомления **выбранной вкладки** (на вкладке «Все уведомления» — все). Поведение и состояния — как у кнопки в дропдауне

---

### Tabs (вкладки)

- Все уведомления
- Системные
- Файлы
- Исследования
- Электронная очередь

---

### Поведение tabs

- Фильтрация уведомлений по типу
- «Все уведомления» показывает полный список
- Переключение вкладок не сбрасывает статус прочитанности
- Обновление данных без перезагрузки

---

## Общая логика уведомлений

- Непрочитанные уведомления сохраняют статус, пока пользователь не увидел их при прокрутке списка или не перешёл по ним
- Просмотр уведомления в списке или переход по нему делает его прочитанным
- После прочтения всех уведомлений индикатор скрывается
- Статус синхронизируется между dropdown, driver-компонентом и другими открытыми вкладками
- Если новые уведомления приходят, пока пользователь прокрутил список вниз, сверху появляется плашка «Новые уведомления»; список при этом не «прыгает»

---

## Состояния Центра уведомлений

| Состояние | Что видит пользователь |
|---|---|
| Загрузка | Заглушки (skeleton) строк списка; при подгрузке следующей порции — индикатор внизу списка |
| Пусто | «Уведомлений нет» с иконкой колокольчика; красный кружок скрыт |
| Ошибка загрузки | «Не удалось загрузить уведомления» и кнопка «Повторить»; уже загруженные уведомления остаются на экране |

## Профиль пользователя

Расположен справа в Header.

Отображает:

- аватар пользователя
- статус присутствия

### Поведение

- Открывает меню пользователя по клику

---

## Меню пользователя

Содержит:

- Профиль пользователя
- Настройки
- Переключение языка
- Выход из системы

---

## Сценарии блокировки

### Отсутствие доступа к ЭМК

1. Поиск показывает пациента
2. При попытке открытия отображается ошибка прав доступа
3. Переход в ЭМК не выполняется

---

### Отсутствие соединения

1. Поиск блокируется
2. Показывается ошибка соединения
3. После восстановления доступ возвращается автоматически
